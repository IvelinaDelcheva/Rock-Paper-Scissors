# Rock, Paper, Scissors 🎮

This is practical project from Soft Uni Course Programming Fundamentals with Python: Rock - Paper - Scissors Game

## About the Project

This is a simple command-line Rock, Paper, Scissors game written in Python. The player competes against the computer, which randomly selects one of the three possible moves. The game compares both choices and determines whether the player wins, loses, or draws.

The game runs in a loop, allowing the player to play multiple rounds until they choose to quit.

### How to Play

1. Run the Python script.

2. Choose Rock, Paper, or Scissors by entering r, p, s, or the full move name.

3. The computer randomly selects its move.

4. The game displays the computer's choice and the result of the round.

5. Enter q or quit to exit the game.
